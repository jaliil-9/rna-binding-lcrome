# Mapping RNA-binders: Publication-Readiness Audit

**Audit date:** 8 September 2026  
**Scope:** Read-only review of the current GitHub repository, source code, reports, and selected computations from archived tables.  
**Audited revision:** [`39daca3fcf0277f6784c70b1f172a9539a382c12`](https://github.com/jaliil-9/rna-binding-lcrome/commit/39daca3fcf0277f6784c70b1f172a9539a382c12), committed 3 September 2026.

## Executive assessment

**My assessment: a substantive basis for a descriptive physicochemical atlas, but not yet a submission-ready, reproducible functional-classification study.** The immediate priority is not another broad analysis phase. It is to reconcile the executable code, frozen cohorts, statistical summaries, and consensus definitions, then write to the strength of the evidence.

The audit found both concrete defects and reassuring checks: the current internal Fisher helper fails; the validation grid and result workbooks use different FDR families; summed overlapping intervals inflate coverage; and an independent reconstruction matches the reported 19.5% consensus figure only when “unanimity among available callers” is used rather than “5/5 agreement” ([internal code](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/lcr_quantitative_analysis.py), [external code](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py), [consensus claims and mapping](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/rbp_proteome_analysis_interpretation/observations_patterns_hypotheses.md)).

Input comparability also needs attention: AlcoR has different raw calls for 1,032 of 1,474 sequence-identical shared proteins, cation–π thresholds differ between the internal/external annotation runs, and 37 annotation rows across both arms lack sequence, including invalid start-zero intervals and titin intervals beyond a truncated workbook sequence ([detector artifacts](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs), [internal annotation](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_annotations.xlsx), [external annotation](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/ensembl_lcr_annotations.xlsx)).

Conversely, recalculating Fisher p-values and applicable Haldane-corrected log2 odds ratios from the archived contingency counts reproduced 4,982 rows across 36 internal/external sheets, and the saved workbook FDR values matched their implemented within-block adjustments ([internal results](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/results), [external results](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/results)). This checks arithmetic conditional on the stored counts, not the biological validity of the cohorts or independence of every statistical unit.

My recommended priority order is:

- **Release gates:** Recover frozen labels and mapping evidence; enforce sequence/coordinate integrity; resolve detector and annotation parity; repair executable stage interfaces.
- **Result corrections:** Unify FDR/eligibility, recompute union coverage, correct consensus denominators, and regenerate cluster cards from the original feature geometry.
- **Claim-dependent follow-up:** Add protein-level inference and stability/length sensitivity where needed for the chosen headline. A descriptive atlas requires less validation than a claim of stable functional classes.

## What was checked, and what was not

- **Repository snapshot:** 503 tracked files and 38 Python scripts were inventoried; all 38 scripts passed syntax parsing, which did not prevent the runtime failure described below ([audited tree](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12)).
- **Data and results:** Cohort counts, FASTA identifiers, shared sequence identity, annotated intervals, binary-test arithmetic, workbook FDR, selected internal continuous summaries, saved clustering labels, consensus reconstruction, and cluster-card consistency were checked against archived inputs and outputs ([dataset files](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/datasets/combined_rbp_pfam38_rbpdb_modomics_uniprot.xlsx), [analysis results](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses)).
- **Boundaries:** No complete detector, HMMER, or clustering rerun was performed. No GitHub files, branches, issues, or settings were changed; the audit report and verification evidence are separate project artifacts.
- **Literature scope:** This was not an exhaustive novelty review or a protein-by-protein biological validation exercise. The upstream AlcoR documentation was checked to resolve a specific methodological description.

“Verified defect” below means a directly observed code/output inconsistency. “Provenance gap” means the necessary evidence was not found in this snapshot, not that the underlying analysis was never done.

## Publication-critical findings

### The current internal statistical script cannot reproduce its categorical outputs

**Status: verified runtime defect.** In `lcr_quantitative_analysis.py`, lines 231–237, `fisher_cell()` calls undefined `chi2_contingency` and `table`, and returns a scalar although its caller at lines 309–310 expects a dictionary; an isolated call with counts `(10, 100, 20, 100)` raises `NameError` ([internal statistical implementation](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/lcr_quantitative_analysis.py)).

The displaced Fisher-style result dictionary appears inside an obsolete `continuous_summary` definition, before a second definition overrides it, indicating code/output version drift rather than evidence that all saved tables are arithmetically wrong ([same implementation](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/lcr_quantitative_analysis.py)).

- **Impact:** A reader cannot regenerate the internal categorical tables with the committed implementation.
- **Minimum correction:** Restore the intended Fisher helper, remove obsolete duplicate definitions, and test ordinary, zero-cell, and small-cell cases. Regenerate a representative method and compare against its archived workbook before rerunning everything.

### Cohort counts must be reconciled, and the external labels must be archived

**Status: verified denominator distinction plus a provenance gap.** The combined workbook has 2,098 rows, but 144 lack accession/sequence and the remaining 1,954 accession-bearing rows reduce to 1,924 unique accessions; the authoritative RBP FASTA contains those 1,924 records ([combined workbook](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/datasets/combined_rbp_pfam38_rbpdb_modomics_uniprot.xlsx), [FASTA](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/datasets/combined_rbp_pfam38_rbpdb_modomics_uniprot.fasta)).

Thus 2,098 is not the number of distinct sequences analyzed, and the difference of 174 is not a set of 174 proven noncarriers; it consists of 144 accession/sequence-missing rows plus 30 duplicate-accession rows ([combined workbook](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/datasets/combined_rbp_pfam38_rbpdb_modomics_uniprot.xlsx)).

All 1,924 accession-resolved unique proteins occur in the global clustering tables, including 138 proteins with no LCR detected by any of the six methods; there is no evidence that 174 otherwise eligible noncarriers were removed from global clustering ([global assignments](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/clustering/global)).

The external outputs consistently report 1,669 RBP-labeled and 18,758 background proteins, but direct accession overlap between the 1,924 RBP sequences and the 20,427-protein background is only 1,474; the external loader requires separate label and covering-accession patch TSVs, which are not present in the tracked snapshot ([headline counts](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/results/summary/tables/headline_numbers.csv), [loader, lines 221–267](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py)).

- **Impact:** The external count arithmetic is internally consistent, but exact positive/negative membership and the mapping beyond direct accession overlap cannot be independently rebuilt from the committed artifacts.
- **Minimum correction:** Export one frozen cohort table with source-row ID, accession, sequence hash, inclusion/exclusion reason, RNA class, background mapping, label source, and patch rationale. Archive the exact external label/patch files; do not reconstruct them by silently guessing from current databases.
- **Manuscript wording:** Distinguish “2,098 candidate-source records,” “1,924 unique analyzed RBP sequences,” and “1,669 positive labels in the reconciled comparison universe.”

The construction report describes that universe as 20,416 reviewed canonical UniProt records plus 11 appended master sequences, not an entirely reviewed Ensembl-canonical proteome ([background construction](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/datasets/rbps_census/ensembl_v116/ensembl_background_construction.md)). Preserve that distinction in the Methods and cohort flowchart.

### Detector parity is unresolved for AlcoR

**Status: verified cross-run disagreement; cause not established.** Among 1,474 accession-matched proteins with identical frozen sequences, 1,032 have different raw AlcoR callsets between the RBP and background runs; the other five configurations have zero callset differences on those same proteins ([raw detector outputs](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs)). Uppercased masked FASTAs match the frozen reference sequences, so this is not explained by an observed input-sequence mismatch, and disagreement already exists before interval merging ([AlcoR artifacts](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs/alcor)).

Both AlcoR manifests record the same model and window but leave threshold/minimum length as binary defaults and lack executable hashes or versions; additionally, all 32,090 background raw CSV rows have `protein_id` equal to `sp` or `tr`, with the actual accession recoverable from the header ([wrapper and run records](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs/alcor)). The wrapper’s first-pipe-field parser explains the malformed identifiers, but the cause of the callset disagreement remains unproven ([wrapper, lines 70–71 and 161–180](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs/alcor/run_alcor.py)).

- **Impact:** AlcoR should not serve as a clean cross-arm biological negative control until run equivalence is established. This does not show that the five matching non-AlcoR configurations are affected.
- **Minimum correction:** Fix header-aware accession parsing; recover executable versions and resolved defaults; test a small identical sequence panel alone, reordered, and embedded in each corpus. Distinguish expected corpus dependence from version or transformation drift before deciding whether a rerun or exclusion is necessary.

### Annotation thresholds and stated exclusions do not match across artifacts

**Status: verified annotation inconsistency.** Cation–π co-occurrence is thresholded at the input-specific 75th percentile: 0.30 in the RBP workbook versus 0.25 in the background workbook; among 14,807 method/accession/coordinate/sequence-matched intervals, 379 have different primary/secondary label tuples and 110 have a different primary label ([annotation implementation, lines 638–644](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/pc_analysis_annotation.py), [internal annotations](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_annotations.xlsx), [external annotations](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/ensembl_lcr_annotations.xlsx)).

For example, P26640 CAST 44–58 is a disorder-rich spacer internally but cation–π-rich externally, despite identical sequence; this limits cross-analysis comparisons, but does not establish different cutoffs within the positive and negative subsets of the background analysis, which both use the background annotation table ([same internal workbook, row 23](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_annotations.xlsx), [same external workbook, row 84139](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/ensembl_lcr_annotations.xlsx)).

The methods document also says LCRFinder calls shorter than 10 residues are excluded, whereas the outputs annotate 5,231/6,371 internal and 42,957/49,657 external LCRFinder calls below that length ([filtering specification, lines 230–233](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_physicochemical_property_analysis.md), [unfiltered iteration, lines 612–650](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/pc_analysis_annotation.py)).

- **Impact:** The same operational label does not always denote the same thresholded sequence property in both analyses. The stated short-call exclusion concerns most LCRFinder calls, not a few exceptions.
- **Minimum correction:** Freeze one explicit reference threshold or use one deduplicated combined annotation table. Decide the actual short-call policy, encode it with an exclusion ledger, and regenerate affected results if the intended analysis requires exclusion; otherwise accurately describe and justify the all-length analysis.

### Invalid coordinates and truncated sequences reach annotation

**Status: verified input-integrity defect.** Internal SEG-intermediate intervals P03950 0–17 and P62945 0–24 violate the declared 1-based inclusive convention and lack sequence, yet persist into annotations; the background contains 13 start-zero calls plus 22 additional missing-sequence annotations for titin, Q8WZ42 ([raw SEG outputs](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs/platoloco), [internal annotations](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_annotations.xlsx), [external annotations](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/ensembl_lcr_annotations.xlsx)).

The background workbook stores only 32,767 titin sequence characters while declaring length 34,350, whereas the frozen detector payload contains all 34,350 residues; missing titin annotation sequences are at coordinates beyond the workbook’s truncated sequence ([background workbook, Combined row 10013](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/datasets/rbps_census/ensembl_v116/finalized_background.xlsx), [frozen background request](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs/platoloco)). The feature extractor converts missing sequence to an empty string and proceeds, rather than quarantining the row ([annotation code, lines 612–626](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/pc_analysis_annotation.py)).

- **Impact:** These 2 internal and 35 external rows should not acquire ordinary sequence features. Their small number does not establish that the headline conclusions change, but the failure mode must be closed.
- **Minimum correction:** Use lossless FASTA as the sequence authority; enforce `1 <= start <= end <= protein_length`, span/sequence-length equality and exact reference slicing before feature extraction. Resolve the upstream coordinate convention rather than blindly incrementing all coordinates, and quarantine unresolved rows with an explicit reason.

### Validation verdicts are not synchronized with workbook FDR or all eligibility flags

**Status: verified code/output inconsistency.** The external workbooks adjust carrier-rate and occupancy sheets separately, whereas the validation-grid path adjusts their combined `b_sig` table; 490 of 936 grid rows therefore have an external q-value different from the matching carrier-rate workbook row, and six cross 0.05, although two remain underpowered ([external code, lines 493–524](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py), [validation grid](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/results/summary/tables/validation_grid.csv)).

For example, CAST snRNA mixed-charge polyampholyte has q=0.043499 in `B_signature_rates` but 0.058790 in the grid and is labeled `concordant_null`; the discrepancy is explained by the two correction families, not an unexplained numerical error ([CAST output](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/results), [validation grid](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/results/summary/tables/validation_grid.csv)).

Retaining the current verdict logic but substituting the workbook q-values changes exactly three verdicts: CAST unknown cation–π and unknown polyampholyte become `externally_validated`, and CAST snRNA polyampholyte becomes `new_external_signal`; neither correction-family choice is automatically uniquely valid, but they must not be mixed without disclosure ([result workbooks and grid](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/results)).

The grid also drops the internal `descriptive_only` flag: strict SEG pre-rRNA acidic enrichment is called `externally_validated` despite an internal table of 13/14 class carriers, leaving one negative cell and explicitly triggering the project’s descriptive-only rule ([grid loader/verdict, lines 385–433](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py), [internal results](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/results)).

- **Impact:** “Validated in X of six callers” counts and some borderline interpretations are not yet a single reproducible result. The word “validated” also describes two comparisons within the project, not replication in an independent experimental cohort.
- **Minimum correction:** Choose and document one multiplicity family per estimand; export adjusted tables once and build verdicts directly from those tables. Carry eligibility flags from both arms and add assertions that matching workbook/grid q-values agree.

There is also a substantive estimand difference: internal signature odds condition on being an LCR carrier, whereas external signature rates include all reconciled class members, so more than the reference population changes ([internal protein construction, lines 451–475](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/lcr_quantitative_analysis.py), [external construction, lines 271–280 and 352–363](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py)). Describe these as two complementary contrasts, or align cohort membership and zero-LCR eligibility before claiming a matched “same metric, different reference” validation.

### Coverage counts overlapping residues more than once

**Status: verified metric-definition defect.** Both internal and external protein summaries sum interval lengths and divide by protein length, but annotated calls can still overlap within a caller, so this is not union coverage ([internal lines 451–456](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/lcr_quantitative_analysis.py), [external lines 271–280](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py)).

In the internal CAST data, 117/1,055 carrier proteins have overlapping intervals and five yield summed coverage above 1; for accession A0A0C4DG89, summed lengths are 460 residues but their union is 371 residues ([annotated intervals](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_annotations.xlsx)).

The corresponding external checks find coverage above 1 in 40 CAST, seven fLPS, and five SEG-intermediate protein-method records; overlaps also occur without exceeding 1, so clipping values to 1 would not solve the error ([external annotations](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/ensembl_lcr_annotations.xlsx)).

- **Impact:** Coverage, residue fractions, and some occupancy/architecture summaries require a declared overlap policy. Binary “at least one detected LCR” incidence is not altered merely by replacing summed lengths with an interval union.
- **Minimum correction:** Compute per-protein/per-method union coverage; define signature-specific unions and the treatment of overlaps between signatures separately. Retaining partially overlapping calls may be intentional, but their shared residues must not be counted twice in a metric named coverage.

The residual overlaps are consistent with the implemented redundancy-reduction rule, which merges at least 70% overlap of the shorter interval rather than every positive overlap; none of the surviving checked pairs violates that threshold ([merge implementation](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs/merge_redundant_lcr.py)). Thus the demonstrated coverage defect should not be misreported as failure to execute the intended merge rule.

## Clustering and interpretation corrections

### Algorithm agreement and figure provenance need narrower claims

**Status: verified qualification and saved-output inconsistency.** PAM and hierarchical clustering agree at ARI=1 for the archived global k=4 partitions, but not for carrier k=5: CAST −0.000684, fLPS −0.000076, LCRFinder −0.003679, SEG 0.414216, and SEG-intermediate 0.000923; HDBSCAN also does not show universal agreement ([global and carrier outputs](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/clustering), [broader ARI wording](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/rbp_proteome_analysis_interpretation/observations_patterns_hypotheses.md)).

### Keep the biological story observational

**Status: interpretation exceeds demonstrated evidence.** The taxonomy specification correctly calls its labels hypothesis-oriented descriptors, yet the synthesis marks active tRNA spacer exclusion, a protein-level recruitment mechanism, and solubility/compatibility design as supported; `frac_disorder` itself is a fraction of disorder-promoting residue types, not a direct disorder measurement ([taxonomy specification](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/lcr_physicochemical_property_analysis.md), [hypothesis board](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/rbp_proteome_analysis_interpretation/observations_patterns_hypotheses.md)).

The external composition tests pool individual LCRs, so multi-LCR proteins contribute repeatedly; the internal continuous tables pair a shared Kruskal–Wallis omnibus p-value with class-versus-rest Cliff’s delta, a distinction that the internal interpretation notes already acknowledge ([external composition code, lines 329–344](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/background_analysis/lcr_background_analysis.py), [internal continuous code, lines 314–335](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/quantitative_analysis/lcr_quantitative_analysis.py)).

- **Minimum correction:** Describe region-level composition as such; for headline protein-level generalization, add a protein-aggregated or protein-resampled sensitivity analysis rather than treating all regions as independent proteins.
- **Minimum wording correction:** Use “candidate physicochemical archetypes,” “disorder-promoting composition,” and “consistent with a proposed mechanism.” Do not infer LLPS activity, G4 specificity, active evolutionary avoidance, or direct LCR-mediated RNA contact from these descriptors alone.
- **Carrier versus occupancy:** Compare prevalence and conditional occupancy as distinct estimands, not log2 odds ratios and Cliff’s delta on a common scale. A weaker occupancy result is not proof that biological effects are absent or that evolution acted only on recruitment.
- **Primary-label hierarchy:** The first-match rule places repeat/charge labels before single-residue labels, so flat late-priority single-AA label counts do not by themselves prove that patterning, rather than composition, is the independent driver ([annotation rule order](https://github.com/jaliil-9/rna-binding-lcrome/blob/39daca3fcf0277f6784c70b1f172a9539a382c12/lcr_analyses/pc_properties/pc_analysis_annotation.py)).

## Minimal route to a manuscript-ready result set

### Repair and freeze before expanding

- **Cohort contract:** Recover the exact label/patch artifacts and reconcile source rows, unique sequences, and external mapped labels.
- **Sequence and detector contract:** Repair/quarantine invalid coordinates and missing sequences; resolve AlcoR parity and raw-ID parsing; pin detector versions and resolved parameters.
- **Annotation contract:** Freeze a common cation–π reference threshold and decide short-LCR eligibility before regenerating features.
- **Executable statistics:** Repair the Fisher helper; make adjusted result tables the single source for verdicts; preserve both arms’ inferential-eligibility flags.
- **Interval contract:** Recompute union coverage and explicitly define signature occupancy and partial-overlap semantics.
- **Consensus contract:** Resolve the 19.5% definition, missing votes, tie handling and mapping; export the full per-protein consensus table.
- **Figure contract:** Regenerate medoids/cards from the frozen feature and distance specification, then lock the representative proteins and figure numbers.

These are necessary corrections or provenance recoveries, not an invitation to rerun every upstream detector. Start with a small end-to-end fixture and archive recovery; then regenerate only the stages downstream of each agreed change.

### Add only checks that protect the selected headline claims

- **Protein-level robustness:** Protein-aggregate or protein-resample the composition comparison; include a family-aware sensitivity if the final conclusion depends on treating related proteins as independent evidence.
- **Annotation robustness:** Check primary-versus-all-signature and threshold sensitivity for whichever archetypes become central, especially cation–π and aromatic/sticker claims.
- **Class contrasts:** Perform a direct snRNA–mRNA contrast only if a distinct snRNA repeat claim is retained; add length-matched ribosomal analysis only if a length-independent depletion magnitude is claimed.
- **Clustering robustness:** Record bootstrap/subsample stability or feature-block ablation for a headline classification claim, rather than using feature-label reconstruction accuracy as functional validation.

### Package the reproducible release

Add a root reproduction guide, dependency/version lock, input checksums, a small smoke-test dataset, explicit output provenance, and a release/data-availability plan. A suitable license and citation metadata should be selected before public release; these are release-readiness tasks, not evidence that the biological observations are wrong.

The repository currently has distributed run guides and valuable saved outputs, but no tracked root README, environment/dependency lock, or dedicated automated test suite was found in this snapshot; the RBP PlaToLoCo request file is empty, limiting direct verification of detector-parameter parity between arms ([audited tree](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12), [detector artifacts](https://github.com/jaliil-9/rna-binding-lcrome/tree/39daca3fcf0277f6784c70b1f172a9539a382c12/rbp_lcrs)).

## Suggested paper and figure structure

- **Cohort and pipeline:** Show candidate-source records → unique analyzed sequences → external comparison universe, with inclusion and mapping rules.
- **Cross-detector incidence:** Show the method dependence and length-stratified comparisons, retaining null or near-saturated methods transparently.
- **Class-associated chemistry:** Lead with protein-level repeat/charge signature prevalence, effect sizes and uncertainty, then use region-level composition as context.
- **Physicochemical archetypes:** Show frozen carrier partitions, explicit caller dependence, per-protein agreement and a correctly defined consensus core.
- **Biological hypotheses:** Present a small number of traceable representative proteins and testable mechanisms, separating region-specific evidence from pathway membership.

**Bottom line:** Finish a bounded reproducibility-and-claim-calibration pass before finalizing the manuscript narrative. The current evidence supports developing an atlas paper; it does not yet support presenting the consensus labels as validated molecular functions.
